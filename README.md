# 📚 Natural Language Processing (NLP)

> **A collection of notebooks covering the fundamental concepts of Natural Language Processing (NLP), including text preprocessing, text representation, part-of-speech tagging, and Word2Vec.**

---

## 📖 Topics Covered

◆ Text Preprocessing

◆ Text Cleaning

◆ Tokenization

◆ Stop Word Removal

◆ Stemming & Lemmatization

◆ Part-of-Speech (POS) Tagging

◆ Text Representation

◆ Bag of Words (BoW)

◆ TF-IDF

◆ Word2Vec (Gensim)

---

## 📂 Repository Contents

| File | Description |
|------|-------------|
| `text-preprocessing.ipynb` | Text preprocessing techniques |
| `Text Preprocessing-half.ipynb` | Additional preprocessing examples |
| `text-representation.ipynb` | BoW, TF-IDF, and text vectorization |
| `POS.ipynb` | Part-of-Speech tagging examples |
| `Blog for W2V.txt` | Notes on Word2Vec |
| `w2v-gensim_model.pdf` | Word2Vec using Gensim |
